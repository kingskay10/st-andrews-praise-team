First Chair Setup

Create the first account in Supabase Authentication, then assign the chair role once in the SQL Editor. This privileged step is intentionally not exposed to the public website.

  1. In Supabase, open Authentication > Users > Add user and create the chair's email/password account.
  2. Open SQL Editor and run the following, replacing the email with the chair's account email:
update public.roles
set role = 'chair'
where user_id = (
  select id from public.profiles
  where email = 'chair@example.org'
);

Then sign in at Member Login. Never put a service-role key into this site.
